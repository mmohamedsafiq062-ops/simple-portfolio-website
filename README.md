## ✨ About the Project

This project is a **personal portfolio website** designed to introduce myself, showcase my interests and skills, and provide an easy way for visitors to get in touch with me.

I created this website as part of my journey into **Web Development** and to strengthen my understanding of the fundamentals of building websites from scratch.

The website focuses on a **simple, clean, and user-friendly design**, with easy navigation between different pages.
